# Changelog

- Initial release of Axius OSS
- Self-hosted server monitoring dashboard
- Local SQLite database (no external SaaS)

- Docker container management
- File explorer with path traversal protection
- Web terminal with multiple sessions
- Email notifications for container events
- First-run setup wizard
- Custom theming via CSS injection
- Dark/light mode toggle
- bcrypt password hashing + JWT sessions
- Docker Compose deployment
